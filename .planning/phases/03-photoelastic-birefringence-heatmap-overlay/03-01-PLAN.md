# Plan 03-01: Photoelastic Chromatic Colormap Generator & Continuous Field Upsampler

<objective>
Implement the foundational colorization and spatial interpolation engines for the Photoelastic Birefringence Heatmap Overlay. Generate a continuous 256-entry OpenCV LUT matching the 3-stop perceptual gradient (Cool Blue ➔ Vivid Amber ➔ Deep Crimson) and build bicubic field upsampling with edge-softening to convert coarse block stress grids into fluid, continuous stress surfaces.

Purpose: Fulfill requirement PHOTO-01 by translating continuous numerical stress fields into physical photoelastic chromatic fringes.
Output: `PhotoelasticColormap` class, `upsample_stress_field` function, configuration models, and unit tests in `tests/test_visualization.py`.
</objective>

  <action>
    1. In `src/config.py`:
       - Add `OverlayConfig(BaseModel)`:
         - `alpha_min: float = 0.15` (translucency in nominal areas)
         - `alpha_max: float = 0.65` (opacity in critical surge areas)
         - `alpha_power: float = 1.2` (non-linear ramp curve)
         - `upsample_blur_ksize: int = 15` (Gaussian kernel for bicubic softening)
         - `hotspot_bloom_radius: int = 40` (pixel radius for radial glow)
         - `hotspot_bloom_intensity: float = 0.35`
         - `contour_levels: list[float] = [0.60, 0.75, 0.90]` (iso-stress contour ratios)
    2. Create `src/visualization/__init__.py`.
    3. In `src/visualization/colormap.py`:
       - Implement `PhotoelasticColormap`:
         - Initializes with 3 color stops (in BGR):
           - Stop 0 (Nominal, 0%): Cool Steel Blue `[229, 136, 30]` (`RGB 30, 136, 229`)
           - Stop 1 (Warning, 50%): Vivid Amber `[53, 216, 253]` (`RGB 253, 216, 53`)
           - Stop 2 (Critical, 100%): Deep Crimson `[47, 47, 211]` (`RGB 211, 47, 47`)
         - Constructs a `(256, 1, 3)` uint8 lookup table (LUT) by linearly interpolating between Stop 0 and Stop 1 across indices 0–127, and between Stop 1 and Stop 2 across indices 128–255.
         - Method `apply(stress_map: np.ndarray) -> np.ndarray`:
           - Clips input to `[0.0, 100.0]`.
           - Scales to `[0, 255]` uint8: `(stress_map / 100.0 * 255.0).astype(np.uint8)`.
           - Runs `cv2.applyColorMap(scaled_indices, self.lut)`.
           - Returns 3-channel BGR uint8 array of the same spatial shape.
         - Method `to_rgb(bgr_image: np.ndarray) -> np.ndarray`: utility to convert BGR to RGB.
    4. In `tests/test_visualization.py`:
       - Write `test_colormap_stops`: Verify index 0 maps to Cool Blue, index 128 maps to Amber, and index 255 maps to Crimson.
       - Write `test_colormap_smoothness`: Verify LUT values change smoothly without sharp discontinuities (adjacent index difference < 5 in all channels).
       - Write `test_colormap_apply`: Verify applying to a dummy float stress array produces expected (H, W, 3) uint8 image bounded in [0, 255].
  </action>
