  <name>Task 1: Stress-Weighted Adaptive Alpha Blender</name>
  <files>src/visualization/overlay.py, tests/test_visualization.py</files>
  <read_first>src/config.py, src/visualization/colormap.py, .planning/phases/03-photoelastic-birefringence-heatmap-overlay/03-CONTEXT.md</read_first>
  <action>
    1. In `src/visualization/overlay.py`:
       - Define `@dataclass OverlayResult`:
         - `blended_frame: np.ndarray` (3-channel BGR uint8 image blended with stress fringes)
         - `rgba_overlay: np.ndarray` (4-channel RGBA uint8 transparent overlay for Streamlit/Web UI)
         - `hotspot_pixel: tuple[int, int]` ((x, y) pixel coordinates of the primary stress peak in target frame)
         - `peak_psi: float` (instantaneous or smoothed PSI)
       - Implement `PhotoelasticOverlayRenderer`:
         - Initializes with optional `OverlayConfig` and `PhotoelasticColormap`.
         - Method `blend_frame(base_frame: np.ndarray, stress_map: np.ndarray, hotspot_coords: Optional[tuple[int, int]] = None, peak_psi: float = 0.0) -> OverlayResult`:
           - Upsamples `stress_map` to match `base_frame.shape[:2]` using `upsample_stress_field`.
           - Computes 3-channel colorized heatmap via `self.colormap.apply(upsampled_stress)`.
           - Calculates adaptive alpha map:
             $$\alpha(x, y) = \alpha_{\min} + (\alpha_{\max} - \alpha_{\min}) \cdot \left(\frac{\text{stress}(x, y)}{100.0}\right)^p$$
             clipped between `[alpha_min, alpha_max]`.
           - Broadcasts alpha across 3 channels and blends:
             `blended = (base_frame * (1.0 - alpha_3d) + color_heatmap * alpha_3d).astype(np.uint8)`.
           - Constructs 4-channel `rgba_overlay` (RGB channels from `color_heatmap` in RGB order, alpha channel `(alpha_map * 255).astype(np.uint8)`).
    2. In `tests/test_visualization.py`:
       - Write `test_alpha_blending_transparency`:
         - Low stress (< 10) blends with alpha ~0.15, leaving base pixels predominantly unaltered.
         - High stress (> 85) blends with alpha ~0.60+, heavily applying the crimson tint.
       - Write `test_rgba_overlay_dimensions`:
         - RGBA overlay has 4 channels and matches input frame dimensions exactly.
  </action>
  <verify>
    <automated>python -m pytest tests/test_visualization.py -k test_alpha_blending -q</automated>
    <fails_when>non-zero exit code or failed assertions</fails_when>
  </verify>
  <acceptance_criteria>

  </acceptance_criteria>
