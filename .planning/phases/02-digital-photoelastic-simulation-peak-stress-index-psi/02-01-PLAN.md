# Plan 02-01: Spatial Density Estimator & Coupled Helbing Stress Field Engine

<objective>
Implement the core mathematical foundation of the Digital Photoelastic Simulation. Extract spatial crowd density from proxy frames and optical flow activity, couple density with velocity variance via Helbing's crowd pressure model, and calculate the continuous 2D stress field and instantaneous 0–100 Peak Stress Index (PSI).

Purpose: Fulfill requirement SIM-01 by translating raw visual motion and spatial compression into an objective, standardized 0–100 mechanical crowd stress metric.
Output: `SpatialDensityEstimator`, `PhotoelasticStressEngine`, configuration models, and unit tests in `tests/test_physics.py`.
</objective>

       - Define `@dataclass DensityResult`:
         - `density_map: np.ndarray` (2D float32 array in [0.0, 1.0], shape matching grid blocks or resized to proxy)
         - `mean_density: float` (mean across grid)
         - `peak_density: float` (maximum block density in [0.0, 1.0])
       - Implement `SpatialDensityEstimator`:
         - Accepts `DensityConfig`.
         - Method `estimate(gray_proxy: np.ndarray, flow_vectors: Optional[FlowVectors] = None) -> DensityResult`:
           - Compute edge gradient magnitude using Canny or Sobel on `gray_proxy` (filtered with Gaussian blur).
           - Resample/pool edge energy into grid blocks of size `block_size x block_size`.
           - If `flow_vectors` is provided, compute normalized motion occupancy per cell (cells with magnitude > threshold considered active).
           - Blend edge energy with flow occupancy: `density = edge_weight * norm_edge + flow_weight * norm_flow`.
           - Clip to strictly [0.0, 1.0].
           - Return `DensityResult`.

  <read_first>src/config.py, src/vision/motion_stats.py, src/physics/density.py, .planning/phases/02-digital-photoelastic-simulation-peak-stress-index-psi/02-CONTEXT.md</read_first>
  <action>
    1. In `src/config.py`:
       - Add `StressConfig(BaseModel)`:
         - `w_density: float = 30.0`
         - `w_variance: float = 25.0`
         - `w_interaction: float = 35.0`
         - `w_stagnation: float = 10.0`
         - `scale_factor: float = 1.0`
         - `percentile_psi: float = 95.0` (percentile used for peak index to eliminate single-pixel noise)
    2. In `src/physics/stress_engine.py`:
       - Define `@dataclass StressResult`:
         - `stress_map: np.ndarray` (2D float32 array in [0.0, 100.0], grid or proxy resolution)
         - `instantaneous_psi: float` (scalar 0.0 to 100.0)
         - `mean_stress: float` (scalar 0.0 to 100.0)
         - `hotspot_coords: tuple[int, int]` ((row, col) coordinates of maximum stress)
       - Implement `PhotoelasticStressEngine`:
         - Accepts `StressConfig`.
         - Method `compute_stress(density_result: DensityResult, flow_result: FlowResult) -> StressResult`:
           - Extract grid density $\rho$ and align grid dimensions with `flow_result.variance_grid` and `stagnation_score`.
           - Normalize components:
             - Density $\rho \in [0, 1]$
             - Velocity variance: normalize `variance_grid` by calibrated expected max velocity variance (e.g. clip to [0, 1]).
             - Interaction term: $\rho \cdot \text{normalized\_variance} \in [0, 1]$.
             - Stagnation factor: `flow_result.stagnation_score \in [0, 1]`.
           - Compute raw 2D stress:
             $$\text{Stress}_{\text{grid}} = w_{\text{density}} \cdot \rho + w_{\text{var}} \cdot \text{Var}_{\text{norm}} + w_{\text{inter}} \cdot (\rho \cdot \text{Var}_{\text{norm}}) + w_{\text{stag}} \cdot \text{Stagnation} \cdot \rho$$
           - Strictly clip `stress_map` to $[0.0, 100.0]$.
           - Compute `instantaneous_psi` using the specified `percentile_psi` (default 95th percentile) of non-zero active cells, or max if sparse, bounded to $[0.0, 100.0]$.
           - Determine `hotspot_coords` (location of maximum stress).
           - Return `StressResult`.
    3. In `tests/test_physics.py`:
       - Write `test_stress_formula_zero_inputs`: zero density and zero flow velocity yield PSI near 0.0.
       - Write `test_stress_formula_max_inputs`: max density and maximum turbulence yield PSI approaching 100.0.
       - Write `test_stress_formula_bounds`: all computed stress values and PSI remain strictly bounded in [0.0, 100.0].
       - Write `test_stress_stagnation_elevates_packed_crowd`: high density with stagnation yields elevated stress even when velocity variance drops.
  </action>
