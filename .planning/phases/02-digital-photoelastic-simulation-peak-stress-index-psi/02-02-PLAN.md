# Plan 02-02: Asymmetric EMA Temporal Smoothing & Hysteresis State Machine

<objective>
Implement temporal smoothing and the 3-tier risk classification engine for ForceSight. Build an asymmetric Exponential Moving Average (EMA) filter (fast-attack / slow-decay) to prevent transient single-frame spikes while ensuring fast surge detection, and a debounced state machine enforcing a 5-point hysteresis buffer and 15-frame hold counter across Nominal, Warning, and Critical regimes.

Purpose: Fulfill requirements SIM-02 and SIM-03 by delivering stable, flicker-free risk alerts with clear operational guidance for security marshals.
Output: `AsymmetricEMA`, `RiskLevel` enum, `RiskStateMachine`, and comprehensive unit tests.
</objective>

       - Add `SmoothingConfig(BaseModel)`:
         - `alpha_rise: float = 0.35` (fast-attack for rapid surge onset)
         - `alpha_fall: float = 0.10` (slow-decay to avoid premature de-escalation)
    2. In `src/physics/risk_state.py`:
       - Implement `AsymmetricEMA`:
         - Initialized with `alpha_rise: float = 0.35`, `alpha_fall: float = 0.10`.
         - State: `_value: Optional[float] = None`, `_map_value: Optional[np.ndarray] = None`.
         - Method `update(current_value: float) -> float`:
           - If uninitialized, `_value = current_value`.
           - If `current_value >= _value`: $\alpha = \alpha_{\text{rise}}$.
           - If `current_value < _value`: $\alpha = \alpha_{\text{fall}}$.
           - `_value = \alpha \cdot \text{current\_value} + (1 - \alpha) \cdot \_value`.
           - Return `_value`.
         - Method `update_map(current_map: np.ndarray) -> np.ndarray`:
           - Vectorized asymmetric EMA on 2D arrays:
             - Element-wise: where `current_map >= _map_value`, use `alpha_rise`, else `alpha_fall`.
           - Return smoothed 2D map.
         - Method `reset()`: resets internal states to None.
    3. In `tests/test_physics.py`:
       - Write `test_asymmetric_ema_attack_vs_decay`:
         - Step up from 0 to 100: reaches > 80% within 4-5 steps.
         - Step down from 100 to 0: takes > 15 steps to drop below 20%.
       - Write `test_asymmetric_ema_map_smoothing`:
         - Tests 2D array smoothing preserving spatial dimensions.
  </action>

<task type="auto">
  <name>Task 2: 3-Tier Risk Classification and Hysteresis State Machine</name>
  <files>src/config.py, src/physics/risk_state.py, tests/test_physics.py</files>
  <read_first>src/config.py, src/physics/risk_state.py, .planning/phases/02-digital-photoelastic-simulation-peak-stress-index-psi/02-CONTEXT.md</read_first>
  <action>
    1. In `src/config.py`:
       - Add `RiskConfig(BaseModel)`:
         - `warning_threshold: float = 50.0`
         - `critical_threshold: float = 75.0`
         - `hysteresis_buffer: float = 5.0`
         - `deescalation_frames: int = 15`
    2. In `src/physics/risk_state.py`:
       - Define `class RiskLevel(str, Enum)`:
         - `NOMINAL = "NOMINAL"`
         - `WARNING = "WARNING"`
         - `CRITICAL = "CRITICAL"`
       - Define `@dataclass RiskStateResult`:
         - `level: RiskLevel`
         - `smoothed_psi: float`
         - `raw_psi: float`
         - `action_recommended: str` ("NORMAL_FLOW", "THROTTLE_GATES", "HALT_INGRESS")
         - `hold_counter: int`
         - `in_hysteresis: bool`
       - Implement `RiskStateMachine`:
         - Accepts `RiskConfig` and optional `SmoothingConfig`.
         - Uses `AsymmetricEMA` internally.
         - Maintains: `current_level: RiskLevel = RiskLevel.NOMINAL`, `hold_counter: int = 0`.
         - Method `process(raw_psi: float) -> RiskStateResult`:
           - Update `smoothed_psi = ema.update(raw_psi)`.
           - Escalation checks (immediate):
             - If `smoothed_psi >= critical_threshold`: escalate to `CRITICAL`, reset `hold_counter = 0`.
             - Else if `smoothed_psi >= warning_threshold`:
               - If `current_level == NOMINAL`: escalate to `WARNING`, reset `hold_counter = 0`.
           - De-escalation checks (buffered by hysteresis & hold count):
             - If `current_level == CRITICAL`:
               - Recovery threshold = `critical_threshold - hysteresis_buffer` (70.0).
               - If `smoothed_psi < 70.0`:
                 - Increment `hold_counter += 1`.
                 - If `hold_counter >= deescalation_frames`:
                   - Drop to `WARNING` (or `NOMINAL` if also `< 45.0` and sustained), reset `hold_counter = 0`.
               - Else: reset `hold_counter = 0`.
             - If `current_level == WARNING`:
               - Recovery threshold = `warning_threshold - hysteresis_buffer` (45.0).
               - If `smoothed_psi < 45.0`:
                 - Increment `hold_counter += 1`.
                 - If `hold_counter >= deescalation_frames`:
                   - Drop to `NOMINAL`, reset `hold_counter = 0`.
               - Else: reset `hold_counter = 0`.
           - Map action:
             - `NOMINAL` -> "NORMAL_FLOW"
             - `WARNING` -> "THROTTLE_GATES"
             - `CRITICAL` -> "HALT_INGRESS"
           - Return `RiskStateResult`.
         - Method `reset()`: resets state to NOMINAL, counter to 0, resets EMA.
    3. In `tests/test_physics.py`:
       - Write `test_hysteresis_immediate_escalation`:
         - Jumping raw PSI from 20 to 80 causes immediate escalation to CRITICAL on first breach.
       - Write `test_hysteresis_debouncing_prevents_premature_deescalation`:
         - Dropping from CRITICAL to 68 for only 5 frames does NOT switch back to WARNING.
         - Dropping from CRITICAL to 68 for 15 consecutive frames transitions to WARNING.
       - Write `test_hysteresis_warning_to_nominal_buffer`:
         - Oscillation between 46 and 49 maintains WARNING without flickering back to NOMINAL.
         - Dropping below 45 for 15 frames returns cleanly to NOMINAL.
  </action>
