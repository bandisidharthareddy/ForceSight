# Plan 04-01: Integrated Pipeline Engine & Plotly Telemetry Components

<objective>
Implement the core end-to-end processing pipeline and telemetry visualizers. Build `ForceSightPipeline` to orchestrate frame ingestion, optical flow motion analysis, spatial density estimation, Helbing stress modeling, asymmetric EMA smoothing, hysteresis debouncing, and photoelastic overlay blending in a single call. Build reusable Plotly telemetry components (semi-circular radial gauge and rolling time-series chart with threshold fences).

  <name>Task 1: End-to-End ForceSight Pipeline Orchestrator</name>
  <files>src/pipeline.py, tests/test_dashboard.py</files>
  <read_first>src/config.py, src/ingestion/video_loader.py, src/vision/tracker.py, src/physics/stress_engine.py, src/visualization/overlay.py</read_first>
  <action>
    1. In `src/pipeline.py`:
       - Define `@dataclass PipelineResult`:
         - `frame_idx: int`
         - `timestamp_ms: float`
         - `blended_frame: np.ndarray` (3-channel BGR image with blended photoelastic fringes and contours)
         - `rgba_overlay: np.ndarray` (4-channel RGBA transparent overlay)
         - `instantaneous_psi: float` (0.0 to 100.0)
         - `smoothed_psi: float` (0.0 to 100.0)
         - `risk_state: RiskStateResult`
         - `hotspot_coords: tuple[int, int]` ((row, col) in grid coordinates)
         - `hotspot_pixel: tuple[int, int]` ((x, y) in full-frame pixel coordinates)
       - Implement `ForceSightPipeline`:
         - Initializes with optional configs (`OpticalFlowConfig`, `DensityConfig`, `StressConfig`, `SmoothingConfig`, `RiskConfig`, `OverlayConfig`).
         - Instantiates:
           - `tracker = OpticalFlowTracker(optical_flow_config)`
           - `turbulence = TurbulenceExtractor(grid_size=density_config.block_size)`
           - `density = SpatialDensityEstimator(density_config)`
           - `stress_engine = PhotoelasticStressEngine(stress_config)`
           - `risk_machine = RiskStateMachine(risk_config, smoothing_config)`
           - `renderer = PhotoelasticOverlayRenderer(overlay_config)`
         - Method `process_frame(frame_data: FrameData) -> PipelineResult`:
           - Extract optical flow vectors: `flow = self.tracker.process(frame_data.gray_proxy)`.
           - If `flow is None` (first frame): create zero flow vectors.
           - Extract turbulence and stagnation: `flow_result = self.turbulence.process(flow)`.
           - Estimate spatial density: `density_result = self.density.estimate(frame_data.gray_proxy, flow)`.
           - Compute continuous stress surface: `stress_result = self.stress_engine.compute_stress(density_result, flow_result)`.
           - Evaluate risk state machine: `risk_result = self.risk_machine.process(stress_result.instantaneous_psi)`.
           - Render photoelastic overlay: `overlay_result = self.renderer.blend_frame(frame_data.raw_rgb, stress_result.stress_map, hotspot_coords=stress_result.hotspot_coords, peak_psi=risk_result.smoothed_psi)`.
           - Return `PipelineResult`.
         - Method `reset()`: resets optical flow tracker, risk state machine, and temporal filters.
    2. Create `tests/test_dashboard.py`:
       - Write `test_pipeline_end_to_end`: processes sample `FrameData` through `ForceSightPipeline` and asserts `PipelineResult` contains valid blended frame, non-null telemetry, and bounded PSI in [0, 100].
       - Write `test_pipeline_reset`: ensures internal state is reset to nominal on `reset()`.
  </action>
  <verify>
