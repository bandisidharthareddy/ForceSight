# Plan 01-01: Video Ingestion Loader and Synthetic Crowd Benchmark Generator

<objective>
Build the video ingestion infrastructure for ForceSight. Scaffold the project dependencies, create the core configuration models, implement the stateful `VideoLoader` stream generator with playback controls (play, pause, loop, frame step), and build `scripts/generate_synthetic_crowd.py` to produce standardized crowd motion test clips for zero-dependency testing.

Purpose: Downstream computer vision and optical flow tracking require reliable, frame-by-frame synchronized image feeds with low-resolution proxies for real-time inference.
Output: Project scaffold, `VideoLoader` class, synthetic crowd video generator, and unit test suite.
</objective>
