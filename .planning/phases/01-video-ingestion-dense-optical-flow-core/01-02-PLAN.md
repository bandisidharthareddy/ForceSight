# Plan 01-02: Farnebäck Dense Optical Flow Tracking and Velocity Turbulence Extraction

<objective>
Implement the computer vision motion tracking and turbulence analysis engine. Wrap OpenCV Farnebäck dense optical flow calculation into an optimized `OpticalFlowTracker` operating on 640x360 grayscale proxies, and build `TurbulenceExtractor` in `src/vision/motion_stats.py` to calculate localized velocity variance and bottleneck stagnation divergence.

Purpose: Downstream Digital Photoelastic Simulation (Phase 2) requires continuous velocity fields and turbulence metrics to compute the 0–100 Peak Stress Index.
Output: `OpticalFlowTracker`, `TurbulenceExtractor`, `FlowResult` data container, and automated tests.
</objective>

  <action>
    1. Create src/vision/__init__.py.
    2. In src/vision/tracker.py:
       - Define FlowVectors dataclass holding:
         - u: np.ndarray (horizontal velocity component, shape HxW)
         - v: np.ndarray (vertical velocity component, shape HxW)
         - magnitude: np.ndarray (polar radius / speed, shape HxW)
         - angle: np.ndarray (polar angle in radians, shape HxW)
       - Implement OpticalFlowTracker class initialized with optional config: OpticalFlowConfig:
         - Maintain prev_gray: Optional[np.ndarray].
         - Implement process_frame(curr_gray: np.ndarray) -> Optional[FlowVectors]:
           - If prev_gray is None, store curr_gray and return None (first frame initialization).
           - Apply cv2.GaussianBlur with kernel size (config.gaussian_blur_size, config.gaussian_blur_size) to both frames.
           - Calculate flow using cv2.calcOpticalFlowFarneback(prev_gray, curr_gray, None, config.pyr_scale, config.levels, config.winsize, config.iterations, config.poly_n, config.poly_sigma, 0).
           - Extract u = flow[..., 0], v = flow[..., 1].
           - Convert to polar using cv2.cartToPolar(u, v, angleInDegrees=False).
           - Update prev_gray = curr_gray.copy().
           - Return FlowVectors(u=u, v=v, magnitude=mag, angle=ang).
         - Implement reset(): clears prev_gray state (used when seeking or looping).
  </action>

<task type="auto">
  <name>Task 2: Velocity Turbulence and Stagnation Extractor</name>
  <files>src/vision/motion_stats.py, tests/test_flow.py</files>
  <read_first>src/vision/tracker.py, .planning/phases/01-video-ingestion-dense-optical-flow-core/01-CONTEXT.md, .planning/phases/01-video-ingestion-dense-optical-flow-core/01-RESEARCH.md</read_first>
  <action>
    1. In src/vision/motion_stats.py:
       - Define FlowResult dataclass containing:
         - flow: FlowVectors
         - grid_variance: np.ndarray (shape grid_rows x grid_cols, representing local velocity variance)
         - avg_speed: float (mean crowd speed across active pixels)
         - stagnation_score: float (normalized 0.0 to 1.0 indicating abrupt deceleration at bottlenecks)
         - active_cell_ratio: float (fraction of grid cells exhibiting movement)
       - Implement TurbulenceExtractor class initialized with grid_size: int = 20:
         - Given flow: FlowVectors with dimensions (H, W):
           - Grid dimensions: rows = H // grid_size (e.g. 18 for 360), cols = W // grid_size (e.g. 32 for 640).
           - For each block (r, c), compute variance of the 2D velocity vectors:
             Var(v) = Var(u) + Var(v). Store in grid_variance array.
           - Compute stagnation divergence:
             Identify regions where incoming velocity magnitude is high (> threshold) adjacent to low velocity (< threshold) in the forward direction. Compute normalized divergence score [0.0, 1.0].
           - Return FlowResult.
    2. In tests/test_flow.py:
       - test_farneback_flow: create two frames where a white square moves 10 pixels to the right. Verify tracker outputs positive u values in the moving region.
       - test_zero_motion: verify tracker on identical frames yields 0.0 max magnitude.
       - test_turbulence_and_stagnation: verify that random chaotic motion yields significantly higher grid_variance than uniform laminar translation.
       - test_pipeline_integration: feed 10 frames from VideoLoader into OpticalFlowTracker and TurbulenceExtractor, verifying valid FlowResult output on each frame.
  </action>
