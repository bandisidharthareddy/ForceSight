    1. Upgrade `scripts/generate_synthetic_crowd.py`:
       - Add `--scenario` argument choices: `["orderly", "bottleneck", "counter_flow"]` (default: `"bottleneck"`).
       - Implement particle simulation logic for:
         - **orderly**: $N=200$ particles flowing with steady rightward velocity ($v_x = 3.0 \pm 0.2$, $v_y = 0.0 \pm 0.1$). No barriers or jamming.
         - **bottleneck**: $N=300$ particles moving towards a gate. At $t = 2.0\text{s}$, gate closes at $x = 0.7 \cdot W$, causing particles to jam and compress against each other.
         - **counter_flow**: Two opposing streams of $N=150$ particles moving in opposite directions ($+v_x$ and $-v_x$), colliding in the center $x \in [0.4, 0.6] \cdot W$ to induce violent directional turbulence.
       - Ensure script generates valid, playable MP4 files with OpenCV VideoWriter.
    2. Create `tests/test_benchmarks.py`:
       - Write `test_benchmark_generation_all_scenarios`: generates temporary 30-frame clips for all 3 scenarios and asserts files exist, are readable by OpenCV, and have correct dimensions.
  </action>

    <fails_when>non-zero exit code or failed assertions</fails_when>
  </verify>
  <acceptance_criteria>

  </acceptance_criteria>

  <files>scripts/run_benchmarks.py, tests/test_benchmarks.py</files>

  <action>
    1. In `scripts/run_benchmarks.py`:
       - Define `@dataclass ScenarioBenchmarkResult`:
         - `scenario_name: str`
         - `total_frames: int`
         - `peak_psi: float`
         - `mean_psi: float`
         - `highest_risk_level: str`
         - `detection_latency_frames: Optional[int]`
         - `avg_fps: float`
         - `stage_latencies_ms: dict[str, float]`
       - Implement `BenchmarkRunner`:
         - Method `run_scenario(video_path: str, scenario_name: str) -> ScenarioBenchmarkResult`:
           - Runs `VideoLoader` through `ForceSightPipeline`.
           - Measures per-stage timing using `time.perf_counter()`:
             - Flow Tracking, Turbulence, Density, Stress Engine, Overlay Rendering.
           - Records peak PSI, mean PSI, first frame reaching Warning/Critical, and overall FPS.
           - Saves the peak photoelastic frame to `data/reports/{scenario_name}_peak.jpg`.
         - Method `run_all(benchmark_dir: str = "data/benchmarks", report_dir: str = "data/reports") -> list[ScenarioBenchmarkResult]`:
           - Runs all scenarios, prints a formatted markdown/terminal summary table, and saves `data/reports/benchmark_report.json`.
       - CLI entrypoint: `if __name__ == "__main__": run_all()`.
    2. In `tests/test_benchmarks.py`:
       - Write `test_benchmark_runner_execution`: runs `BenchmarkRunner` on a synthetic clip, verifies results return valid metrics, and asserts average FPS is $\ge 24.0$.
  </action>
